Carnella 2.0 - Mental Health Support Bot 🇰🇪



A Kenyan-themed mental health support chatbot built with Python and Tkinter.





\- 🇰🇪 Kenyan cultural context with Sheng/Swahili support

\-  Crisis detection with local helpline numbers (Befrienders Kenya: 0722 178 177)

\-  Beautiful, accessible GUI with Kenyan flag colors

\-  Quick-reply buttons for common emotions

\-  Timestamped chat history

\-  Modern, colorful interface
